# Configuration Guide - Telegram Downloader

Telegram Downloader features a centralized, 4-tier configuration system with strict precedence:

```
1. Environment Variables (TELEGRAM_DOWNLOADER_*)
         ↓
2. Configuration File (%ProgramData%\TelegramDownloader\config\config.json)
         ↓
3. Database Settings (SQLite settings_store table)
         ↓
4. Safe Built-in Defaults
```

---

## 1. Configuration File Reference

The configuration file is stored in `%ProgramData%\TelegramDownloader\config\config.json`:

```json
{
  "host": "0.0.0.0",
  "port": 8787,
  "download_dir": "D:\\TelegramDownloads",
  "log_level": "INFO",
  "max_concurrent_downloads": 2,
  "free_space_threshold_mb": 1024,
  "max_retries": 3,
  "retry_delay_seconds": 15,
  "is_production": true,
  "secret_key": "<auto-generated-hex-key>",
  "telegram_api_id": 28941234,
  "telegram_api_hash": "3a89e9d91f894123456789abcdef0123",
  "telegram_phone": "+1234567890",
  "jellyfin_url": "http://192.168.1.50:8096",
  "jellyfin_api_key": "your_jellyfin_api_key",
  "jellyfin_auto_refresh": true
}
```

---

## 2. Setting Keys & Explanations

| Key | Default | Type | Description |
| :--- | :--- | :--- | :--- |
| `host` | `"0.0.0.0"` | String | Interface IP to bind web server (use `0.0.0.0` for LAN/Tailscale). |
| `port` | `8787` | Integer | HTTP port for the web dashboard. |
| `download_dir` | `null` | String | Target storage folder for downloaded files. Must be valid Windows path. |
| `log_level` | `"INFO"` | String | Logging verbosity: `DEBUG`, `INFO`, `WARNING`, `ERROR`. |
| `max_concurrent_downloads` | `2` | Integer | Maximum parallel downloads. Recommended: `2` to `4` for Intel Core i5-7300U. |
| `free_space_threshold_mb` | `1024` | Integer | Minimum free disk space in MB required before starting a download (1024 MB = 1 GB). |
| `max_retries` | `3` | Integer | Number of automated retries before marking a download as `FAILED`. |
| `retry_delay_seconds` | `15` | Integer | Wait time in seconds between retry attempts. |
| `telegram_api_id` | `null` | Integer | 32-bit signed integer from [my.telegram.org/apps](https://my.telegram.org/apps). |
| `telegram_api_hash` | `null` | String | 32-character API Hash from [my.telegram.org/apps](https://my.telegram.org/apps). |
| `telegram_phone` | `null` | String | International format phone number (e.g. `+1234567890`). |
| `jellyfin_url` | `null` | String | Base URL of Jellyfin server (e.g. `http://192.168.1.50:8096`). |
| `jellyfin_api_key` | `null` | String | API token from Jellyfin Dashboard -> API Keys. |
| `jellyfin_auto_refresh` | `false` | Boolean | If true, automatically triggers Jellyfin library scan when downloads finish. |

---

## 3. Environment Variables (Overrides)

You can override any parameter using environment variables prefixed with `TELEGRAM_DOWNLOADER_`:

- `TELEGRAM_DOWNLOADER_PORT=9000`
- `TELEGRAM_DOWNLOADER_LOG_LEVEL=DEBUG`
- `TELEGRAM_DOWNLOADER_DATA_DIR=E:\CustomAppData`
- `TELEGRAM_DOWNLOADER_MAX_CONCURRENT_DOWNLOADS=4`
